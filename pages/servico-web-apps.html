O que está por baixo

Uma web app é feita de quatro peças que conversam entre si. Defino cada uma contigo antes de construir.

Interface

React, Next.js ou JavaScript simples

API

Python (FastAPI), PHP ou Java

Base de dados

PostgreSQL, MySQL ou Redis

Autenticação

Contas, sessões e áreas reservadas

Para quem é

Para quem precisa de contas de utilizador, dados guardados ou uma API.

Uma ferramenta de gestão, uma plataforma de reservas, uma app que organiza informação pública.

Trabalho sozinho, por isso o tamanho do projeto conta. É a primeira coisa de que falamos na conversa.

O que inclui

Tudo o que uma aplicação precisa para funcionar no dia a dia, do ecrã à base de dados.

  • Interface em React, Next.js ou JavaScript simples
  • API em Python (FastAPI) ou PHP
  • Base de dados em PostgreSQL ou MySQL, com o esquema desenhado por mim
  • Autenticação e áreas reservadas
  • Mockup antes de construir, com uma ronda de ajustes
  • Deploy com Docker e ajuda com domínio e HTTPS
  • Código entregue num repositório teu

Fica à parte

  • Funcionalidades fora do que combinámos: orçamentadas antes de avançar.
  • Conteúdo e dados iniciais: fornecidos por ti.
  • Servidor e serviços externos: dependem do uso e ficam em teu nome.

Como decorre

Do primeiro contacto ao suporte, em quatro fases.

Fase 1

Perceber

Antes de qualquer valor ou contrato.

01

Conversa

Uma chamada para perceber o problema, quem vai usar a aplicação e o que tem de funcionar primeiro.

02

Mockup

Desenho os ecrãs principais e discutimos antes de escrever código. Sem custo, com uma ronda de ajustes.

Fase 2

Acordar

Tudo por escrito, antes de começar.

03

Proposta e contrato

Envio a proposta e o contrato, com o âmbito, o valor e o prazo. Nos projetos maiores, a entrega pode ser dividida em fases.

Fase 3

Construir

Com pontos de situação pelo caminho.

04

Construção

Construo a interface, a API e a base de dados. Vês a aplicação a funcionar à medida que cresce.

05

Revisões

Com o projeto terminado, tens duas rondas de alterações incluídas antes da entrega.

Fase 4

Lançar

A aplicação chega aos utilizadores.

06

Lançamento

Publico a aplicação e configuro o domínio e o HTTPS. O código fica num repositório teu.

07

Suporte

Acompanho o arranque depois da entrega. O suporte e a manutenção ficam definidos na proposta.

Orçamento

Cada web app é diferente, por isso o orçamento vem depois da conversa e parte do que o projeto realmente precisa: quantos tipos de utilizador há, que painéis existem e com que serviços tem de falar.

A proposta chega por escrito, com o valor fechado. Só começo quando a assinares. A conversa e o primeiro mockup não custam nada.

Fases e entregas parciais

Os projetos maiores podem ser divididos em fases, com entregas parciais. Assim vês o progresso e podes ajustar o rumo pelo caminho.

O código fica contigo

No fim, entrego o repositório com o código. Depois do pagamento final, o projeto é teu.

Servidor e serviços externos

Os custos de servidor e de serviços externos dependem do uso e ficam em teu nome. Digo-te à partida o que podes esperar.

Manutenção

Depende da dimensão do projeto e fica definida na proposta. Uma aplicação com vários painéis e utilizadores pede mais cuidado do que um site simples: atualizações de segurança, cópias de segurança e monitorização.
